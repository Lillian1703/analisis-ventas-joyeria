# Análisis de Ventas de una Joyería

## 📌Descripción del Proyecto

Este proyecto consiste en el análisis exploratorio Y predictivo de un conjunto de datos de ventas de una joyería con el objetivo de identificar patrones de comportamiento, productos más vendidos, tendencias temporales y oportunidades de mejora para la toma de decisiones comerciales.

El análisis fue realizado utilizando Python y bibliotecas especializadas para manipulación, limpieza, visualización y predicción de datos.

---

## 🎯 Objetivos

- Analizar el comportamiento histórico de las ventas.
- Identificar los productos, sucursales y clientes con mayor desempeño.
- Aplicar modelos predictivos y red neuronal para la optimización de precios y gestión de inventarios.
- Generar visualizaciones para apoyar la toma de decisiones.

## 🛠️ Tecnologías Utilizadas

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-Learn

## 📊 Dataset

El conjunto de datos contiene información relacionada con las ventas realizadas en una joyería durante casi una década.

### Variables principales

| Variable | Descripción |
|----------|-------------|
| Id_Cliente | Id del cliente |
| Id_Artículo | Id del artículo vendido |
| Pago | Tipo de pago |
| Fecha | Fecha de venta |
| Zona | Sucursal |
| Precio | Precio del artículo |

## 📈 Análisis Realizados

### Análisis General de Ventas 

-Ticket promedio
-Total transacciones
-Total ventas


### Ventas por año

Comparativa de las ventas anuales a lo largo de 10 años

### Productos Más Vendidos

Identificación de los productos con mayor volumen de ventas.

### Ventas por cliente

Identificación de clientes que generan mayor participación al total de ventas.

### Indicadores Clave (KPIs)

- Ventas Totales
- Ticket Promedio
- Número de Transacciones
- Producto Más Vendido
- Zona con Mayores Ventas
